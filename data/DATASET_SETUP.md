# Dataset Setup

## IAM Handwriting Database

This project uses the IAM Handwriting Database for handwriting
analysis and computer vision development.

The IAM dataset is not stored in this GitHub repository.

## Local Directory

After downloading the IAM dataset, place the required files under:

data/raw/IAM/

Expected structure:

data/raw/IAM/
├── images/
├── xml/
└── ascii/

## Important

Do not commit or push the raw IAM dataset to GitHub.

The `data/raw/` directory is excluded through `.gitignore`.

## Metadata

The metadata structure is currently under development.

Do not create or modify the final metadata schema until the
team agrees on the structure.
