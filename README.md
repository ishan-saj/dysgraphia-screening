# dysgraphia-screening

Explainable computer vision framework for early dysgraphia
risk screening using handwriting data.

## Project Objective

Develop a computer vision based system that analyzes handwriting
patterns and provides an explainable dysgraphia risk assessment.

## Current Dataset

IAM Handwriting Database

The IAM dataset is being used for handwriting analysis and
computer vision development.

## Project Structure

- `data/` - dataset-related files and metadata
- `src/` - Python source code
- `notebooks/` - experiments and analysis
- `docs/` - research and methodology documentation
- `experiments/` - experiment configurations and logs
- `results/` - experimental results

## Status

Currently:
- Dataset exploration
- IAM XML/metadata analysis
- Metadata schema design
- Handwriting feature extraction development

## Important

The IAM dataset is not a dysgraphia-labelled clinical dataset.
Clinical dysgraphia labels must come from an appropriate
clinically labelled dataset.
